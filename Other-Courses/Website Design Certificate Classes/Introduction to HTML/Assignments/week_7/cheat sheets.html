HTML5 Cheat Sheets

HTML5 includes many new tags, which earlier versions of browsers might ignore,
thereby not rendering the page properly.
That's why it's especially important for users to have the latest versions of browsers;
new versions can also contain stronger security and encryption blocks.

Exercise
In our Resources module, you'll see HTML5 cheat sheets. Where possible, include new HTML5 tags into your Index page, including the header and footer tags. Especially, ensure that your single-sided tags comply with HTML5.

As always, check out our HTML Cheat Sheet for tools and information.
