Essay on Non-Standard additions to HTML

Should page authors use non-standard additions to HTML? No, absolutely not, but of course that couldn't be the case in the beginning when the web was just starting. Even when most websites contained only text (imagined as a circle) and would work on any browser (circular hole), there would be others that either wouldn't fit, or could fit, but not perfectly (putting a circle into a square hole). As the web progressed, different browsers made users create different versions of their website to work on each browser, and each time there was an update, there was a chance your website wouldn't work anymore. Without standards, it would let browsers determine what features would be part of the web.

With the introduction of web standards, it became possible for websites to be cross-compatible with many different browsers by just including a script so that it works on said browser. It also helped websites interact with assistive technologies so browsers and web developers can incorporate instructions into their pages which can then be interpreted to provide a common experience for the user no matter which browser is used.

Web standards are very helpful in that many developers can work on a website and understand what the previous person was during. In contrast, if another developer wanted to continue working on a website that another had dropped, they would have a lot of trouble understanding the structure and design of the website if they didn't have the same knowledge and coding practices as the author. But, how did standards become common practice? With a lot of discussion on what features should be normalized. But, where did they choose those features from? Even before something becomes a standard, it would have likely been widely used across many browsers, so the role of the standard is to set out the expected use for new features to adhere to and outline how browsers and developers can conform to this expectation, that way any new addition can work in any environment.

TLDR: It's like language. There have been tens of thousands of different languages over the course of human history (Many different browsers). You have to learn a new language to be able to talk with the people (Code for the website to work on the browser). It would be much easier if there was only one language, or maybe a few that had similar grammar and meaning you could easily understand, so that everyone wouldn't have to take time to learn many different languages just to be able to understand each other.
