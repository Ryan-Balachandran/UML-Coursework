What are virtual instruments?

    Virtual/software instruments are used to create sounds on a computer. Virtual instruments are a cost effective alternative to buying actual instruments like guitars, drums, and synthesizers. You'll want an appropriate midi controller to use in tandem with your virtual instruments. Maybe you'll need something with piano keys or something with finger pads. It all depends on your needs. When acquiring virtual instruments, make sure they are compatible with Linux.

    Setup and Installation

    Once you install your virtual instrument, you will need understand how to use a software app called Jack to get it running. It comes with the Ubuntu Studio operating system and is the central hub where all of your virtual instruments connect to the system.
