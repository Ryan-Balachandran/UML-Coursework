Motherboards and CPU

    Any 32 or 64 bit Intel or ARM compatible computer (other hardware can be used if you build Ardour yourself or have someone else build it for you). CPU speed limits the amount of signal processing you can do.

    RAM

    Minimum of 2GB is recommended, more is always better.
    [Shop for RAM at NewEgg]

    Hard Drives

      • One System Drive
        • Minimum 16GB free space for Ubuntu Studio OS.
        • Minimum 350MB of free space in the /opt folder to install Ardour.
      • You will want lots more disk space for recording. Since we want to be sure all of our musical creations are saved for posterity, you'll want one hard drive for storing your recordings and another for backing them up.
        • [Shop for hard drives at NewEgg]


    USB 3 Card

    Most of the peripheral devices you'll be connecting to your computer are going to require USB 3 connectivity. Your motherboard likely provides a few of these connections, but chances are, you'll need more. It is best to invest in a USB 3 PCIe card with 5-7 ports. I recommend this over a USB 3 hub because unlike a hub, the card plugs directly into the motherboard, ensuring that your devices are getting the best connection possible.
    [Shop for USB 3 Cards at NewEgg]

    Wireless Keyboard and Mouse

    While it certainly isn't a requirement, I do recommend using a wireless keyboard and mouse. I find that during my studio workflow, I frequently find myself moving the keyboard and mouse to make room for some other peripheral that I need in front of me. I like the Logitech Unifying USB devices, because the receiver only takes up one USB port for up to 6 devices and it has a range of 33 feet.
