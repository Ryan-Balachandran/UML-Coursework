    A Little Backstory

    This website is dedicated to providing basic information about setting up a digital home recording studio, using the Ubuntu Studio Linux operating system and opensource software.

    My interest in this topic stems from a need to revamp my entire setup. Back in the day, I used something called ProTools. I had the LE (light edition) version, which was geared more toward nobodys like me, whereas the professional versions were geared more toward... well, professionals.

    Eventually, my LE version could no longer be upgraded without more than I was willing to spend. I was stuck with this old version of Protools LE, running on a windows xp machine. ProTools these days, has become a subscription service, and I really don't like that.

    Linux and the opensource community would turn out to be the answer to my woes. Hopefully, the things that I've learned since embarking on this adventure will be of some use to someone, somewhere, someday.
