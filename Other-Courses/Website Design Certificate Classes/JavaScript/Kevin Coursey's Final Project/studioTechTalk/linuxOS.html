What is Ubuntu Studio

    Ubuntu Studio is a free and open source operating system, and an official flavor of Ubuntu. Ubuntu Studio is the most widely used multimedia-orientated operating system in the world. It comes preinstalled with a selection of the most common free multimedia applications available, and is configured for best performance for various purposes: Audio, Graphics, Video, Photography and Publishing.

    Setup and Installation

    Once the download completes, and you have the ISO burned to a DVD or you have made a bootable USB stick, boot your machine from that media. The ISO you downloaded is a live image, which means you can try it without actually installing it. If you like it, then there are two installation options.

    Ideally, you have a dedicated machine for this installation. The first option overwrites all the data on your disk. Choose this option only are installing Ubuntu Studio on a dedicated computer. If you are repurposing a computer for Ubuntu Studio, be sure to save anything that is important to you before doing the install.

    The second option creates a dual boot system. Choose this option if you are installing Ubuntu Studio on a machine that also needs to keep its original operating system in tact. After doing the install, your computer will give you the option to either boot into your old system or into the new Ubuntu Studio system. This option can be tricky, requires that you understand disk partitioning and is not recommended for novice users. If you feel confident that you can handle it, check out the Ubuntu Dual Boot page for more information.
