What is a MIDI Controller

    A MIDI controller puts the control of the software right in your hands. For example, it's more intuitive to use the controls on a mixer to work with sound, instead of using a computer keyboard and mouse. The MIDI controller connects to your computer via USB. Your needs will determine what types of controllers you will buy. When using recording and editing software, you'll want one with knobs, faders, and section for transport controls like, play, stop, fast forward, rewind, etc. For DJ projects, a DJ controller would be more appropriate as it would come with not only knobs and faders, but would include decks similar to those on an actual turn table and a crossfader. Other MIDI controllers may come in the form of piano style keyboards with finger pads for triggering drums or sound samples. Learn more

    Buying a Controller

    Most software for audio production make it very easy to configure MIDI controllers. Some even have a learn feature where you can click items on the screen and associate them with features by moving or pressing the desired control on the controller. This website focuses on Ardour, which has an exhaustive set of features that can be manilpulated via a MIDI controller. Just about everything you can do in Ardour with a mouse, you can control via MIDI. Ardour comes preinstalled with many MIDI maps ready to use. If your particular controller is not listed, creating a map is relatively simple by creating a file using XML syntax.
